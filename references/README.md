# Referencias visuales — Ferretería y Construcciones El Conejo C.A.

Esta carpeta contiene las referencias visuales aprobadas para implementar el frontend.

## Reglas importantes para una IA/agente de código

- Usar estas imágenes como referencia de UI/UX, no como fuente de datos reales.
- No hardcodear números, nombres, ventas, stock, fechas o métricas que aparecen en los mockups.
- Mantener el mismo lenguaje visual entre todas las pantallas: fondo claro, sidebar claro, azul como color principal, tarjetas blancas, bordes suaves, esquinas redondeadas y espaciado consistente.
- Verde = positivo/disponible; naranja = advertencia; rojo = crítico; azul = navegación/acción principal.
- La marca real es **Ferretería y Construcciones El Conejo C.A.**; “Ferretería Pro” es solo texto de los mockups.
- Usar `00_marca/logo_oficial_el_conejo.png` como logo oficial.
- No usar nada dentro de `90_archivo_no_usar/` para implementar la UI final.

## Estructura

- `00_marca/`: logo oficial.
- `01_inicio/`: pantalla de inicio.
- `02_inventario/`: referencias del módulo de inventario incluidas en este paquete.
- `03_compras/`: órdenes de compra, proveedores y recepciones.
- `04_analisis_predictivo/`: pronóstico, reabastecimiento, precisión y tendencias.
- `05_configuracion/`: configuración general, análisis predictivo, notificaciones, usuarios y roles, seguridad y respaldo.
- `90_archivo_no_usar/`: duplicados o referencias antiguas que pueden confundir a un agente.
